# 非同期保存中の編集巻き戻り (2026-05-30)

## 症状

保存処理の待機中に続けて編集すると、先に始まった保存の完了後にエディターが古い内容へ戻り、新しい内容が保存されないことがあった。

## 原因

修正コミット `60861e37` に記録された `executeSave` は、`saveFileByPath` の await 後に無条件で保存タイマーを消し、保存開始時の content で全タブを更新していた。await 中に新しい入力が入ると、この処理が新入力向けのタイマーを消し、store を古い内容で上書きした。React の再描画後、CodeMirror/Monaco にも古い値が渡った。

## 修正と再発防止

保存完了後に現在のタブ内容を再取得し、保存開始時の内容と一致する場合だけタイマーを消して保存済み状態を反映する。内容が変わっていれば新しい store 値と debounce timer を維持し、次の保存に任せる。

保存処理では await 前に読んだ値が完了時にも最新とは限らない。完了時の状態を確認せずに store やタイマーを更新すると、後続入力を失う。
